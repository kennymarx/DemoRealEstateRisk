## 16 个文件职责一览

| 文件                 | 职责                                               |
| :------------------- | :------------------------------------------------- |
| `main.py`            | 串联四阶段：OCR → Excel → 风险分析 → 汇总表        |
| `config.py`          | 所有可调参数                                       |
| `rate_limiter.py`    | 线程安全令牌桶限流器                               |
| `llm_client.py`      | 大模型 HTTP 封装（多图 + 重试 + 限流 + JSON 抽取） |
| `scanner.py`         | 遍历项目、定位财报文件夹、列图片                   |
| `cache_manager.py`   | 按批次哈希缓存 OCR 结果                            |
| `ocr_processor.py`   | 分批送图 + 合并多批次                              |
| `excel_writer.py`    | 输出「明细」+「宽表」两个 sheet                    |
| `risk_analyzer.py`   | 组装 prompt，输出结构化风险报告                    |
| `summary_manager.py` | 汇总表 + 备份 + 指纹 + Excel 导出                  |
| `risk_inputs.json`   | 人工维护的外部风险信息                             |
| `run.sh` / `run.bat` | 一键启动                                           |
| `README.md`          | 使用说明                                           |
| `requirements.txt`   | 依赖                                               |
| `.gitignore`         | Git 忽略                                           |
